# Browse the commit graph

## Sub-features

Local and remote branch sections, branch filtering, the full graph of every branch, squash-merge edges, ref labels beside the graph, per-commit line changes, optional Author, Date, and SHA columns, keyboard movement, hidden and soloed branches, branch highlight on ref hover, author nodes, jumping to a branch tip from the sidebar, windowed rows, loaded-history search, and local refresh.

## How to get to it (user POV)

Add the fixture's `repository` path. L1 Git opens on the repository screen. Expand **Local branches** and **Remote branches** in the sidebar. The graph always reads local and remote branches, tags, and HEAD. Columns are **Branch / Tag**, **Graph**, **Commit message**, and **Changes**. Right-clicking the header row opens **History columns**, which also offers **Author**, **Date**, and **SHA**. Internal refs and stashes are excluded.

## Gotchas

The graph holds at most the newest 50,000 commits. Past that, the summary reads `Newest 50,000 commits`, and selecting a branch whose tip is older shows the notice `<branch> is older than the newest 50,000 loaded commits.` Search covers loaded subjects, authors, emails, and IDs. It does not query older commits. Under a hide or solo rule, search, keyboard movement, and the branch highlight cover only the commits the graph shows. A commit selected before a rule hid it stays selected in the inspector without a row. Down and Shift+Down from it select the nearest shown commit below, and Up and Shift+Up the nearest above. With `main` soloed and the `feat/squashed` tip selected, Down selects `Merge branch feat/history` and Up selects `feat(search): search loaded history (#2)`. With no shown commit left in a direction, the move goes the other way. From the same hidden selection, search `feat` and press Enter. Confirm the selection moves to `Merge branch feat/history`, the first match below the hidden commit, not to the top of the history. Select the hidden tip again and press Shift+Enter, and confirm `feat(search): search loaded history (#2)` is selected. Choosing Hide while branches are soloed, or Solo while branches are hidden, replaces the rule with one for that branch. A fixture used by another journey may have additional commits; recreate it to recover the nine-commit baseline. GitHub metadata displays `l1-family/l1-git` without a network request.
