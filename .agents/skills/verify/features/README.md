# L1 Git feature journeys

| Journey                                                                               | User outcome                                                                                                   | Proof                                                                                                                                                      |
| ------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Add and restore repositories](repositories.md)                                       | Open a working copy and keep it across restarts                                                                | Visible list, canonical path, unchanged files                                                                                                              |
| [Browse the commit graph](history.md)                                                 | See every branch in one graph and jump to a branch tip                                                         | Full graph, selected tip, unchanged HEAD                                                                                                                   |
| [Inspect a commit](inspector.md)                                                      | Read the message, parents, and changed paths, or compare two commits                                           | Merge and root details, working parent links, compared paths                                                                                               |
| [Read a file diff](diff.md)                                                           | Read one changed file's patch in place of the history                                                          | Unified and split diffs, binary notice, Escape back                                                                                                        |
| [Change appearance](appearance.md)                                                    | Choose System, Light, or Dark without losing the repository view                                               | Saved preference, live system changes, themed workspace and diffs                                                                                          |
| [Update behind branches](overview.md)                                                 | Fetch saved repositories, fast-forward ready branches, and push to the configured upstream or publish to a reviewed remote and destination | Moved refs match the count, one reviewed remote branch changes, review invalidation, paired tracking settings, independent tracking failure, refreshed graph and outgoing counts  |
| [Connect an existing endpoint](overview.md#connect-an-existing-endpoint-before-publication) | Add a remote inside Publish branch and continue explicit publication review | Atomic shared URL and fetch mapping, preserved destination, no add-time network or refs, Enter routing, stale response guards, refresh-only recovery |
| [Stage, unstage, commit, discard, and undo](changes.md)                               | Stage, unstage, commit, amend, and discard, then undo and redo each write                                      | Index, refs, and file bytes before and after, exact undo, stale-view and hook notices                                                                      |
| [Create, rename, delete, and check out branches, and create and delete tags](refs.md) | Make, rename, remove, and check out branches and commits, make and remove tags, then undo and redo each        | Refs, branch settings, HEAD, status, and the index before and after, Git's name and checkout reasons, tag objects after gc, stale and checked-out refusals |
| [Check, download and install app updates](updates.md) | Choose Stable or Nightly, download a verified release, and restart with explicit all-draft-loss consent | Signed fixture download and replacement, resulting version, all-root activity exclusion, cancel and failure recovery |
| [Merge into the current branch](merge.md) | Select local or remote sources, review exact refs and plans, Finish or Abort, and resume after restart | No-tracking sources, no-op and fast-forward outcomes, pinned destination, two-parent commits, resolution Undo, safe Abort, and restart recovery |
| [Read real repository data](reader.md)                                                | Receive accurate repository states                                                                             | Automated real Git and HTTP integration tests                                                                                                              |

Browser and native journeys use real working copies. Reader and build checks passed for the implementation baseline. UI journeys require a live verification pass.

The [conflict resolver journey](changes.md#resolve-a-stash-text-conflict) covers source versions, Pierre choices and editing, separate Save and Mark resolved, ordered Undo/Redo, retained drafts, and restart protection.
